# ByteFest 2026 Registration Website

This is the first front-end prototype.

## Run
Open `index.html` in Chrome, Edge, or Firefox.

## Current features
- Responsive ByteFest landing page
- Events section
- Schedule and basic rules
- Event-specific registration selection
- Team registration form
- Automatic demo registration ID
- Registrations stored locally in the browser

## Important
This version does NOT have a real shared database. If you open the site on another computer, its registrations will not appear there.
